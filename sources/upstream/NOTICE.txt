Cardgroove ATR reference data

This is a transformed, deduplicated reference collection, not an official card
identity service. No identification has been verified against physical hardware.
The original sources and notices are distributed alongside the dataset.

The exact commit, source URLs, checksums and retrieval timestamp are recorded
in manifest.json. This is a selection of drivers, not all OpenSC-supported cards.

The combined atrs.json reference dataset is redistributed under GPL-2.0-or-later.
Changes: source format conversion to JSON, normalization, duplicate merging,
classification as Exact/Pattern/Masked, and addition of source provenance.
Source descriptions are retained, including uncertainties and possible errors.
The website does not claim ownership of these source descriptions or relicense
them as MIT. A matching ATR can correspond to more than one card/application.

Refresh/transformation source: import-atrs.mjs and atr-catalog.mjs in this folder.
Their original project paths are scripts/import-atrs.mjs and
